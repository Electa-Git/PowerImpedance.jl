PowerImpedance.jl

PowerImpedance models AC, DC, and hybrid power systems for frequency-domain analysis. Build a network from component models, calculate its operating point when needed, and inspect impedance or small-signal stability results.

Install

Add the package with Julia's package manager:

pkg> add PowerImpedance

Load it in Julia with:

using PowerImpedance

Your first analysis

Follow the Getting started tutorial to calculate an operating point for a single-machine infinite-bus system. The example also displays the network and plots impedance and Nyquist results.

Find a guide

  • Component definitions and inputs explains how to choose models and set their values.
  • Component guides: voltage sources, lumped impedances, transformers, lines and cables, machines, MMC, two-level converter, and black-box models.
  • Network construction explains buses, individual nets, and diagrams.
  • Power-flow initialization explains when an operating point is needed.
  • Impedance and stability analysis covers calculations, result objects, and plots.
  • Parametric and uncertainty studies covers deterministic and Monte Carlo studies.
  • Examples contains larger executable workflows.
  • API reference lists public functions and types.

Optional integrations and plotting backends are described in Package extensions.

Capabilities

Models include voltage sources, impedances, transformers, lines and cables, converters, synchronous and induction machines, and black-box responses. Analyses include impedance, admittance, Nyquist, Bode, passivity, small-gain, stability-margin, unstable-frequency, and eigenvalue calculations.

The theoretical background retained from the original package documentation is cited in the project bibliography.
