Two-level converter

tlc returns a TLC model assembled from electrical, measurement, synchronization, control, modulation and delay blocks. It declares ac = Port(ACDQ) and dc = Port(DC_CM).

using PowerImpedance

converter = tlc(
    sync = PLLSynchronization(),
    outerActive = OuterActivePowerControl(),
    outerReactive = OuterReactiveQControl(),
    innerCurrent = InnerCurrentPIControl(),
)
b = bases(converter)
configured = withinputs(converter;
    outerActive = (p_ref = 100.0/b.S,),
    outerReactive = (q_ref = 0.0,),
    powerflow = (v_ac = 1.0, v_dc = 1.0),
)
inputvalues(configured).outerActive
(p_ref = 0.2, support = NamedTuple())

References and converter power-flow setpoints are per unit on bases(converter). BaseValues reports MVA, phase-peak AC kV, pole-to-pole DC kV, and rad/s. inputs describes the nested input tree selected by the control blocks. inputvalues returns the configured values. component also accepts replacement limits. TLC Limits use MW and MVAr for power-flow bounds.

The powerflow group contains p_ac, q_ac, v_ac, p_dc and v_dc. Selected loops supply their controlled quantities. Remaining quantities use the stored setpoints. A setpoint for a quantity already supplied by a loop warns and is ignored during target selection. powerflow.p_dc is positive into the DC port.

After power flow, op[:c1] contains physical values at ac and dc for a converter named c1. Powers are positive into each port. A converter receiving 603 MW from DC and delivering 600 MW to AC has dc.p = 603 and ac.p = -600. linearize(converter, op[:c1]) returns a StateSpaceLinearization with the converged state and continuous-time system. steady_state(converter, op[:c1]) computes the equilibrium without forming the electrical system. Each call computes from the solved terminal values and leaves the model unchanged.

Gridspace accepts deterministic and uncertain values in the constructor tree. A numeric sample is solved and linearized before its response contributes to the statistics. See Component definitions and inputs, tlc, TLC, and Power-flow initialization.
