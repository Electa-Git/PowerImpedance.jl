PSCAD component mapping

The abbreviations are defined in the export guide.

The exporter translates solved networks into PSCAD 5 projects. The tables describe component fields, electrical conventions and generated control equations. The manual suite in test/manual/pscad/validation/README.md describes frequency-response and time-domain measurements. XML checks verify the written project. A native build and measured response test its execution in PSCAD.

AC source Ph = rad2deg(va) + 90 converts Julia's cosine angle to PSCAD's sine reference. The dq convention is d=cos(theta), q=-sin(theta). A matrix frame change acts on rows and columns.

MMC uses vAC_base, 2*Sbase/(3*vAC_base) and pole-to-pole vDC_base. Its physical transformer already converts the measured voltage and current to the converter side. Synchronous-machine terminal Y is converted from pu by Sbase/VLL^2.

Modules, canvases and layout

Main and each module connect ports through named nodes. Each connecting wire is a straight segment with two vertices. It joins one known port to a label or ground. Ports cannot coincide. Stubs cannot share endpoints or pass through another port or label. Every electrical port, signal input and label requires a stub. Signal names are case-insensitive and require one same-canvas writer. Imports and module outputs write signals. Exports, recorders and module inputs read them. Meter names and machine POut/QOut also write signals.

Electrical module ports require a wire from their xnode anchors to an internal node label, including when both names match. Empty series paths identify electrical labels without adding a component. Line rows contain geometry and material records without circuit pins.

Generated names reject PSCAD intrinsic identifiers case-insensitively. Name reservations include network, module and probe identifiers. Saved transform fragments retain parameters, orientations and pin-net partitions while their coordinates and wires are relocated.

Every canvas, including Main and line definitions, uses sheet size=5. Instance origins and absolute wire vertices must lie in [0,14382] on both axes. BlockGraph lowers in stored order, four rows per column, with columns six grid units apart and rows four apart. Signal stubs are 36 pixels. Two/three-input sums use D/F/B and disable unused inputs. Set definition.module=true before adding blocks with mhi-xml 1.3.0.

Module input forms require intent="Input", dim="1", finite bounds, helpmode="Append", and cond, help, vis children. The writer uses add_real/add_integer/add_text. Parameter.help_mode writes the correct attribute. Real bounds are ±1e308, integer bounds signed 32-bit, text bounds 0/0. The XML node supplies dim because the creation API has no dimension option. Connected references such as AVR vref and governor Tm0 use the import output. Const accepts numeric literals. Block parameters accept literals or plain form names. Compute products, ratios and initial values in Julia. Electrical component parameters inside modules must be finite SI literals.

Probed shunts use bus -> element -> meter -> ground. Parallel shunts share a return meter. Consecutive ideal meters on an isolated floating YY secondary can cause a native zero diagonal. Moving the load meter to its ground return reproduced the reference load current 0.215 kA without changing passive parameters. The structural check follows galvanic islands through module ports and paired interfaces, excluding voltage probes as conducting paths.

test/pscad/topology.jl compares serialized electrical graphs with independent reference graphs. It retains ordered pins, component, material and fitting parameters and module connections, while ignoring coordinates, IDs and internal label spelling. Isomorphic cable interfaces are matched. Nets require two attached ports unless grounded or carrying a voltage probe. Only listed shunt-meter moves are accepted. Unlisted moves and meter reversals fail.

Synchronous-machine realization

The machine uses sm_equivalent_circuit. Reactances use per unit. The external branch is R=rt*Zbase, L=lt*Zbase/ωn, Zbase=Vᵃᶜ_base^2/S_base. The branch represents impedance on the same voltage base. Machine VT/Pheta refer to the terminal before rt/lt, with angle plus π/2. P0/Q0 come from solved generator power. External current corresponds to the receiving end of the internal branch.

The AVR applies 1/(1+s*T_R), vref-v_f, (1+s*T_C)/(1+s*T_B), K_A/(1+s*T_A) and field-voltage conversion. Ts=0 avoids adding a second measurement pole. \[V_t = V_{bus} + (r_t + j l_t) I, \qquad S_t = V_t I^* = p_{pf} + j q_{pf},\]

The manifest retains probe names, units, element, side and direction. Machine channels include P/Q in MW/MVAR, Vt and speed in pu, plus Ef0/Ef/Tminit initialization diagnostics. MMC adds six `<e>vCtot{u,l}{a,b,c}channels in kV and<e>iSzonSbase/vDCbase. Rotatingtheta_c` is diagnostic. Its nominal growth produces a settling warning even at a stable operating point.

Operating-point comparisons use public-bus fundamental machine and converter P/Q, internal converter P/Q means, DC pole differences and current magnitudes. Power error is divided by device MVA rating. Machine terminal voltage is reconstructed through the exported rt/lt values. MMC capacitor cycle means compare with solved pole-to-pole Vdc. Signed DC current compares with 3*mean(iS_z)*Sbase/vDC_base. The powerflow column contains that measured current reference.

Converter-connected DC currents use abs(measured_kA-reference_kA)/max(abs(reference_kA),Sbase/vDCbase). DC connectivity propagates this base through branches, excluding ground and AC terminals. Identical converter bases can share an island. Differing bases raise an error. Converter-free networks retain relative current error.

Legacy OUT output contains an .inf channel list, .infx, and numbered .out files with at most 10 channels each. Array names append the element index, starting with name:1 and name:2. OUT starts with a description line, followed by time and numeric values with carriage-return and line-feed (CRLF) endings. Expected rows are round(T/sample_step)+1. PSCAD writes to project.temp_folder, normally <case dir>\<project>.gf81\.

The validation runner subtracts identical zero-amplitude baselines, uses coherent rectangular windows and requires an odd integer recording interval to integration step ratio. That ratio prevents EMT-Nyquist chatter folding to DC. The validation README describes KCL timing, reference selection and comparison limits.

Known limitations

Julia's fixed-frame dq reduction of an untransposed line can be non-passive. For the 170 km IEEE9 line, the minimum Hermitian admittance is -0.005134 S in dq versus +0.0005009 S in phase coordinates. With a 100 MVA TLC at bus 2, the dq model predicts a growing pair near 124.24/124.34 kHz (+2.37 s⁻¹). The phase-domain harmonic calculation gives -670.4 s⁻¹, converged at K=1..3. The IEEE9 circuit with a TLC was not run in PSCAD. Use phase-domain frequency-response and stability comparisons when untransposed line asymmetry affects the frequencies of interest.

Untransposed AC lines produce steady negative-sequence unbalance and ±100 Hz image coupling that a fixed-frame dq LTI comparison omits. With untransposed flat lines, the redesigned P2P's c2 current has 2.7 % negative sequence and its bus voltage has 0.32 % negative sequence. The image ratio reaches 0.50 and response errors are 14–21 %. The P2P circuit with AC grids has 1.35 % negative-sequence current and 0.61 % negative-sequence bus voltage at c2, image ratios of 0.32–0.59 and about 49 % response error. The redesigned P2P uses untransposed lines and requires phase-domain comparison. Ideal transposition remains available in Julia. PSCAD projects with Transp = 1 exit abnormally at termination, preventing successful PSCAD measurement runs.

Line fitting and DC extrapolation

Tighter YMaxE=AMaxE=0.02 % targets reduce fit-versus-own-constants terminal-Y error over 1–1000 Hz. AC cable/DC cable/DC overhead-line maxima are 0.84/0.49/0.35%, versus 4.34/2.88/4.31% at 0.2% targets. Increasing only Numf=400 gave 3.68/7.32/4.09%. More sample points alone did not improve these fits. Constants differences and fit errors have separate denominators.

At FS=0.001 Hz, DCenab=0, a DC cable fit gives 0.484 ohm per pole at s=0 versus 0.272 ohm in Julia (+77.8%). At 0.001 Hz it gives 0.275 ohm (+1.07%), with 2.17% full terminal-Y error. The DC OHL true-DC resistance error is 0.257 % on a 2.00 ohm reference. The fit's true-DC limit requires evaluation at s=0. One cable fit has a 260 s pole. DCenab=1 fails cable Yc fitting with Error in INVCJD. Singularity occurs. The export retains the specified lossless dielectric inputs.

Small DC powers

A TLC near-zero-power case at 10 us measured -63.7 kW converter DC power and +50.2 kW source absorption. The network fundamental power calculation real(S_M*exp(jδ)), with δ=2π*50*10e-6, predicts -63.7 kW and matches the unrounded signed measurement within 0.95 mW. This supports a one-step voltage and current alignment explanation, with a reactive-power cross term around 63.8 kW. The remaining 21.2 mA cable-end difference can include low-frequency fit conductance and settling. Its physical cause remains unresolved.

Unsupported controls and circuits

DCVoltageSupportLag and non-NoFilter VAC/DC outer-control filters raise “not yet exportable” before equilibrium recovery. Nontrivial energy power_filter and nonzero CCC references need a separate Σ-generator review. Exposed cable sheath and armour interfaces, AC counts other than three and DC line counts other than two are unsupported.

Distributed-line travel time and licence size

Emitters warn when length/299_792_458 m/s < time_step. PSCAD uses its own calculated travel time and aborts when it is shorter than the integration step. A 100 m OHL/cable measured 0.329/0.648 us. It cannot run at 10 us. Reduce the integration step or explicitly change physical section length.

The recorded educational licence permits 200 electrical nodes and one subsystem. IEEE9 uses 78 live nodes. Both recorded IEEE39 representations use 528 and build with only the node-cap error, zero warnings. Their exports pass offline checks. They were not run in PSCAD under that licence. Licence usage counts the internal component nodes as well as bus conductors.

P2P instability

PSCAD reproduces the instability Julia predicts for the original P2P. Julia locates two growing modes at signed abc frequencies +3478.5 Hz with growth 1374 s⁻¹ and -3476.6 Hz with growth 1426 s⁻¹. The fresh-start record at 1.0 us fits a growing mode at +3543 Hz and 1630 s⁻¹ over 0.3–1.8 ms. Frequency is 1.9 % and growth is 19 % above Julia's +3478.5 Hz mode. The second mode remains unresolved, with a fit at -4122 Hz.

The record is nonlinear in that interval. AC line energisation from the uncharged start gives 11.5 pu peak departure and arm insertion indices outside [0,1]. The harness status is invalid_measurement, and the growth rate is not determined to 10 %. A separate phase-a trace at 1 us fits 3473 Hz and a 0.688 ms growth time (1453 s⁻¹) over 0.3–1.8 ms. That interval was chosen after inspecting the record.

For the P2P with AC grids without its 80 km line, Julia's +160.6 Hz mode at 55.0 s⁻¹ completes 0.24 cycles in the 1.5 ms fit interval. Its 2 ms records cannot show that mode. EMTDC steps of 0.2 and 0.25 us fail at the converter-transformer star point. Steps of 0.5 and 1.0 us run.

The 200 us modulation delay interacts with the roughly 3 kHz overhead-line resonance. Differential modulation-delay states account for 98.81–98.84 % of explicit converter-state participation, with distributed-line states excluded.
