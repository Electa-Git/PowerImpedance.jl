API reference

The public interface is grouped by its defining module. Ordinary component constructors and downstream solvers belong to PowerImpedance. Gridspace construction, study definitions, and result containers belong to PowerImpedance.Grammar and are re-exported by the package root and PowerImpedance.NetworkBuilder.

PowerImpedance

Component ports are declared by Port, ACDQ, ACABC, DC_CM and electricalconnections. Configurable inputs use Input, inputs, inputvalues, withinputs and component. Bases and limits are available through BaseValues, bases and limits. Control references and converter or machine power-flow setpoints use the model bases. Source and scan-based MMC inputs use physical units.

Terminal operating points use ACPortValues and DCPortValues, keyed by port name in a NamedTuple. OperatingPoint stores these NamedTuples by element name: op[:c1].ac.p accesses AC active power into the component, and op[:c1].dc.v accesses DC voltage. get(op, :missing, nothing) returns nothing for an absent element. linearize(model, values) returns a StateSpaceLinearization with equilibrium state and continuous-time system. steady_state(model, values) computes the same equilibrium without forming the electrical system. Each call computes a new result and leaves the model unchanged.

PowerImpedance.AVRSM — Type
struct AVRSM <: PowerImpedance.AbstractStateSpace

Regulate synchronous-machine terminal voltage with a measurement filter, lead-lag compensator and exciter lag.

  • v_ref::Float64: Configured terminal-voltage reference [dimensionless], superseded by the effective reference at a power-flow operating point. Default: AVRVOLTAGE_INPUT.default

  • T_R::Float64: Terminal-voltage measurement-filter time constant [s]. Default: 0.05

  • T_B::Float64: Lead-lag denominator time constant [s]. Default: 1.0

  • T_C::Float64: Lead-lag numerator time constant [s]. Default: 0.1

  • T_A::Float64: Exciter-lag time constant [s]. Default: 0.02

  • K_A::Float64: Regulator gain [dimensionless]. Default: 200

Notes

At equilibrium, the open-circuit field voltage is

\[E_f = K_A(v_{ref} - |V_t|),\]

where $E_f$ denotes field voltage, $V_t$ terminal voltage and $v_{ref}$ its reference in [dimensionless]. The regulator gain is $K_A$. A complete machine power-flow point sets the fixed effective reference to $v_{ref} = |V_{t,pf}| + E_{f,pf}/K_A$ and requires nonzero K_A. The configured v_ref field remains unchanged. Without a complete operating point, the standalone AVR and machine use v_ref without reference conversion or phasor initialization.

PowerImpedance.DCVoltageSupportLag — Type
struct DCVoltageSupportLag <: AbstractFrequencySupport

Subtract lagged DC-voltage support from the active-power reference. Measured voltage and the solved reference use the declared DC-voltage base.

  • K::Float64: Droop gain in normalized active power per normalized DC voltage [dimensionless]. Default: 0.0

  • ωc::Float64: First-order low-pass cutoff in [rad/s]. Default: 0.0

  • v_dc_ref::Float64: DC-voltage reference on converter bases [dimensionless]. Default: DCVOLTAGESUPPORTINPUT.default

Notes

\[\dot{\xi}_{vdc,supp}=\omega_c[K(v_{dc,ref}-v_{dc,f})-\xi_{vdc,supp}], \qquad p_{ref,eff}=p_{ref}-\xi_{vdc,supp}.\]

Here $v_{dc,ref}$ denotes the solved DC-voltage reference, $v_{dc,f}$ the filtered DC voltage and $\xi_{vdc,supp}$ the lag state. The effective active-power reference $p_{ref,eff}$ uses the converter's pu base, as do voltages and the lag state. The cutoff $\omega_c$ has units [rad/s] and $K$ is droop gain in pu power per pu voltage.

struct SynchronousMachine <: PowerImpedance.AbstractStateSpace

Represent a synchronous machine in the dq frame with modified Kundur electrical equations, steam turbine, governor, lead-lag AVR, and exciter. Electrical quantities use the three-phase S_base [MVA] and line-to-line RMS Vᵃᶜ_base [kV] bases.

Notes

For a complete power-flow point, Pac and Qac are generator-terminal powers [MW] and [MVAr], while phase-peak Vac [kV] and θac [rad] describe the receiving bus after the external rt/lt branch. At synchronous speed, fixed references include armature loss and field excitation:

\[T_{m0} = p_{pf} + R_a |I_{pf}|^2, \qquad v_{ref} = |V_{t,pf}| + E_{f,pf}/K_A.\]

Here $p_{pf}$ denotes terminal active power, $R_a$ armature resistance and $I_{pf}$ terminal current, on machine pu bases. Terminal voltage $V_{t,pf}$ and field voltage $E_{f,pf}$ also use machine pu bases. The AVR gain is $K_A$. The effective reference replaces avr.v_ref in the equations while the configured field remains unchanged. Initial states use the power-flow phasors and the high-voltage solution of the external branch. Turbine fractions must sum to one for Tm0 to equal total turbine torque. References remain fixed during linearization.

Bus(name; ports, domain = nothing) connects named component ports and expands into one net per coordinate. AC names append d, q or a, b, c. A DC net retains the bus name.
