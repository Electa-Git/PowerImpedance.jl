# Z-tool library fixture

`Z_tool.pslx` is the unmodified library from
[Z-tool v0.1.52](https://github.com/Electa-Git/Z-tool/tree/v0.1.52),
`Source/ztoolacdc/Scan/Z_tool.pslx`. Z-tool uses the GPL v3 licence.
The SHA-256 is
`5924f4fbb112a110457b531016a9bd5c8f61125903044eb78d331feb607151ed`.

The fixture supports offline library-copy, cache, XML parameter and port checks.
The [export guide](../../../../docs/src/pscad.md#Z-tool-scan-probes) gives the
publication citation.

The mixed AC/DC fixture keeps three data rows from the repository's MMC
reference file. Its header places the DC axis before the AC axes.
